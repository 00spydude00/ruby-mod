# Ruby Mod


### Summary

Ruby Mod is a minecraft mod made in fabric (java) with ruby tools, armor, ore, ore generation, textures etc. 

This is an open source project. For more information, see LICENSE.


### Rubies


Rubies are the main ingredient in all new features added by this mod. 

They are meant to be an upgrade over the current best materials in the game (diamond and netherite)

In future patches, ruby is planned to be balanced as more of an alternative for these materials.


#### Obtaining Rubies


Rubies can be obtained by mining Ruby Ore or Deepslate Ruby Ore with a Diamond or better pickaxe (including ruby pickaxes).

Normal interactions with fortune and silk touch enchantments apply to Ruby Ores.


Ruby ores have a wide range of y-levels where they generate:

Ruby Ore: stone replaceables from y=0 to y=70

Deepslate Ruby Ore: deepslate replaceables from y=-64 to y=16 (y=16 is the highest y level with natural deepslate)


### Tools

### Armor


Armor includes:

Helmet, Chestplate, Leggings, Boots


#### Tool and Armor Recipes


Recipes for tools and armor are the same as typical tool recipes with rubies substituted for other materials.
